# Understand a Recurring Failure

Use this for a recurring or difficult bug, not after every fix. Trace the cause
and explain why earlier fixes missed it. Follow Phase 2.3/3.2 in
`.trellis/workflow.md`. Preserve only a useful lasting finding in the existing
package docs/spec or task PRD. No mandatory retrospective, new regression test,
report, journal or Git operation.
